# Proxy reference data (no human gold set was used)

- planform_bioelectric.jsonl, planform_publications.csv: exported from the Planform database v2.5.0
  (Lobo D, Malone TJ, Levin M. Planform: an application and database of graph-encoded planarian regenerative
  experiments. Bioinformatics 2013;29(8):1098-1100). Redistributed under its free-use licence with attribution;
  records are reproduced as Planform stores them, not re-interpreted. Outcomes are frequencies, not counts.
