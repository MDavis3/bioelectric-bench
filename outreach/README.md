# Outreach drafts (optional)

The run never depends on outreach and never sends anything. Cold requests for unpublished data rarely work.

If a draft is worth writing, give first:
- Run the lab's own published data through the benchmark and lead with a finding about their work.
- Ask for one specific, small thing (one table, one experiment), not "unpublished data".
- Offer credit, or co-authorship if the result goes somewhere.

Files: request_<lab>.md, and levin_lab_note.md at the end.
